{{- $Ordinal := $.Ordinal -}} {{- $IsBlock := $.IsBlock -}} {{/* URL originale et suppression du fragment CSS */}} {{- $srcOriginal := .Destination | safeURL -}} {{- $fragments := split $srcOriginal "#" -}} {{- $srcWithoutFragment := index $fragments 0 -}} {{/* Nom du fichier et extension */}} {{- $filename := path.Base $srcWithoutFragment -}} {{- $ext := lower (path.Ext $filename) -}} {{/* Largeur maximale par défaut */}} {{- $imgwidth := .Page.Scratch.Get "imgwidth" | default 800 -}} {{/* Recherche dans les ressources Hugo disponibles */}} {{- $images := union (union (.Page.Parent.Resources.ByType "image") (.Page.Resources.ByType "image") ) (resources.ByType "image") -}} {{- $image := $images.GetMatch (printf "**/%s" $filename) -}} {{- $isSVG := or (eq $ext ".svg") (and $image (strings.Contains (lower $image.MediaType.Type) "svg")) -}} {{/* Les images utilisées comme blocs peuvent être redimensionnées. Les images inline sont simplement affichées avec leur URL originale. */}} {{- if $IsBlock -}} {{/* SVG : pas de .Width / .Height / .Resize (Hugo ≥ 0.167). */}} {{- if $isSVG -}}
{{/* Image raster trouvée dans les ressources Hugo : JPG, JPEG, PNG, WebP, GIF, etc. */}} {{- else if and $image (not $isSVG) -}} {{- $resized := $image -}} {{- $resizeWidth := $imgwidth -}} {{- $hasMeta := and $image.Width $image.Height -}} {{/* Portrait : limite 600 px si métadimensions disponibles */}} {{- if and $hasMeta (gt $image.Height $image.Width) -}} {{- $resizeWidth = 600 -}} {{- end -}} {{/* Redimensionnement uniquement si nécessaire */}} {{- if and $hasMeta (gt $image.Width $resizeWidth) -}} {{- if hugo.IsExtended -}} {{- $resized = $image.Resize (print $resizeWidth "x webp") -}} {{- else -}} {{- $resized = $image.Resize (print $resizeWidth "x") -}} {{- end -}} {{- end -}} {{/* Les GIF animés ne doivent pas être redimensionnés, sinon l'animation peut être perdue. */}} {{- if eq $image.MediaType.SubType "gif" -}} {{- $resized = $image -}} {{- end -}} {{/* Placeholder basse résolution pour les JPEG opaques. */}} {{- $placeholder := "" -}} {{- if or (eq $image.MediaType.SubType "jpg") (eq $image.MediaType.SubType "jpeg") -}} {{- $placeholder = $image.Resize "48x q20 jpg Gaussian" -}} {{- end -}}
