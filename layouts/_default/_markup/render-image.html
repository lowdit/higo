{{- $Ordinal := $.Ordinal -}} {{- $IsBlock := $.IsBlock -}} {{/* URL originale et suppression du fragment CSS */}} {{- $srcOriginal := .Destination | safeURL -}} {{- $fragments := split $srcOriginal "#" -}} {{- $srcWithoutFragment := index $fragments 0 -}} {{/* Nom du fichier et extension */}} {{- $filename := path.Base $srcWithoutFragment -}} {{- $ext := lower (path.Ext $filename) -}} {{/* Largeur maximale par défaut */}} {{- $imgwidth := .Page.Scratch.Get "imgwidth" | default 800 -}} {{/* Recherche dans les ressources Hugo disponibles */}} {{- $images := union (union (.Page.Parent.Resources.ByType "image") (.Page.Resources.ByType "image") ) (resources.ByType "image") -}} {{- $image := $images.GetMatch (printf "**/%s" $filename) -}} {{/* Les images utilisées comme blocs peuvent être redimensionnées. Les images inline sont simplement affichées avec leur URL originale. */}} {{- if $IsBlock -}} {{/* SVG : Ne pas utiliser .Width, .Height ou .Resize, car ces propriétés peuvent provoquer une erreur avec certains SVG. */}} {{- if eq $ext ".svg" -}}
{{/* Image raster trouvée dans les ressources Hugo : JPG, JPEG, PNG, WebP, GIF, etc. */}} {{- else if $image -}} {{- $resized := $image -}} {{- $resizeWidth := $imgwidth -}} {{/* Les images portraitives sont limitées à 600 px de largeur */}} {{- if gt $image.Height $image.Width -}} {{- $resizeWidth = 600 -}} {{- end -}} {{/* Redimensionnement uniquement si nécessaire */}} {{- if gt $image.Width $resizeWidth -}} {{- if hugo.IsExtended -}} {{- $resized = $image.Resize (print $resizeWidth "x webp") -}} {{- else -}} {{- $resized = $image.Resize (print $resizeWidth "x") -}} {{- end -}} {{- end -}} {{/* Les GIF animés ne doivent pas être redimensionnés, sinon l'animation peut être perdue. */}} {{- if eq $image.MediaType.SubType "gif" -}} {{- $resized = $image -}} {{- end -}} {{/* Placeholder basse résolution pour les JPEG opaques. */}} {{- $placeholder := "" -}} {{- if or (eq $image.MediaType.SubType "jpg") (eq $image.MediaType.SubType "jpeg") -}} {{- $placeholder = $image.Resize "48x q20 jpg Gaussian" -}} {{- end -}}
